# Real Ads + Premium Setup

## Ads
1. Create an AdMob account.
2. Register the Social Chat Android app.
3. Create ad units for banner/native/interstitial placements.
4. Put the official App ID and ad-unit IDs into the Android project.
5. Use test ads during development.

## Premium
1. Create/publish the app in Google Play Console.
2. Create subscriptions:
   - socialchat_premium_monthly
   - socialchat_premium_yearly
3. Connect Google Play Billing.
4. Verify purchases before granting premium entitlements.
5. Test with Google Play license/test accounts.

## Important
Do not put private server credentials in the Android APK.
Real monetization cannot be activated from source code alone without the developer's AdMob and Play Console accounts.
