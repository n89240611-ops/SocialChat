# Firebase connection

1. Create a Firebase project.
2. Add an Android app with package name:
   com.socialchat.app
3. Download `google-services.json`.
4. Put it inside the `app/` folder.
5. Enable Authentication providers:
   - Email/Password
   - Phone
6. Create a Firestore database.
7. Publish `firebase/firestore.rules`.
8. Build the app and test with two separate accounts.

Do not share service-account private keys or other server credentials.
